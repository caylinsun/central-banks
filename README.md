# Central Bank Watch

A compact learning dashboard comparing seven major central banks for Caylin's CUHK MBA Money and Capital Markets course (FINA6010E).

It compares policy levers, current rates, latest decisions, mandates, transmission channels, leadership backgrounds, committee stance, learning prompts, news and named references.

## Method

Rates, decisions and news are tied to dated source publications. Hawkish and dovish labels are evidence-based interpretations of the latest decision, vote and communication; they are not permanent descriptions of a committee or individual.

## Publishing

GitHub Pages publishes the static dashboard in `dist` after each update to `main`.
